Questions

  1. Explain the difference between inline, embedded, and external CSS. - Inline is style within the tags, embedded is in the Head tag of an html page, external is a seperate file that can be used over and over again
  2. Explain why you should only use external CSS. - "Seperation of concerns" For that when it is a bigger company, you will have different people with different specialties, so you want to keep them seperated. Another reason is so that it is easier for consitence across pages.
  3. What is a selector used for? - The selector in the CSS file that chooses what tags are affected by the style
